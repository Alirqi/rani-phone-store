# متجر راني فون للهواتف

متجر إلكتروني عربي RTL بتصميم أسود وذهبي، يعمل كواجهة أمامية ثابتة دون خادم أو قاعدة بيانات.

## التشغيل محلياً
افتح `index.html` في المتصفح، أو استخدم إضافة Live Server في VS Code.

## تخصيص المنتجات
افتح `script.js` وعدّل مصفوفة `products`:
- `name`: اسم الهاتف
- `brand`: Apple أو Samsung أو Xiaomi (للفلاتر)
- `price`: السعر بالدولار
- `specs`: وصف مختصر
- `tag`: شارة اختيارية
- `image`: رابط صورة مباشر (ضع رابط صورة مباشر)

رقم واتساب مضبوط حالياً على `967774859996` ويمكن تغييره من المتغير `WHATSAPP`.

## النشر المجاني عبر GitHub Pages
1. ارفع ملفات هذا المشروع إلى جذر مستودع GitHub العام.
2. افتح Settings ثم Pages.
3. من Build and deployment اختر Deploy from a branch.
4. اختر `main` والمجلد `/ (root)` ثم Save.
5. بعد اكتمال النشر سيكون الرابط عادة:
   `https://alirqi.github.io/rani-phone-store/`

## ملاحظات مهمة قبل استقبال العملاء
- أسماء الهواتف والأسعار الحالية أمثلة تجريبية وليست عروضاً مؤكدة.
- أضف صور المنتجات الحقيقية وروابطها في `script.js`.
- هذه النسخة لا تتضمن لوحة إدارة أو قاعدة بيانات أو دفعاً إلكترونياً؛ الطلبات تُرسل إلى واتساب.
- صور الهواتف الحالية تستخدم روابط ملفات من Wikimedia Commons. قبل الاستخدام التجاري، راجع ترخيص كل صورة وصفحة مصدرها، أو استبدلها بصور تملك حقوق استخدامها.
